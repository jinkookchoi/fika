# 경쟁 앱 조사 — TomatoBar & Stretchly

> Fika 개발 참고용. macOS 휴식/뽀모도로 메뉴바 앱 시장의 대표 무료·오픈소스 두 앱을 분석한다.
> 조사일: 2026-06.

---

## 1. TomatoBar 🍅

> "World's neatest Pomodoro timer for macOS menu bar"
> https://github.com/ivoronin/TomatoBar — MIT

### 한 줄
**메뉴바 전용 미니멀 뽀모도로 타이머.** 우리와 가장 비슷한 결(네이티브 Swift, 메뉴바 중심, 가벼움).

### 핵심 기능
- 작업/휴식 인터벌 커스터마이즈
- 전환 사운드 (켜고 끄기)
- **전역 단축키**로 시작/정지
- **URL 스킴 제어** — `tomatobar://startStop` (CLI·자동화·Shortcuts 연동 가능)
- 상태 전환을 **JSON 로그**로 기록 → 생산성 분석 (우리 `Log`와 유사)
- "discreet actionable notifications" (조용한 알림)

### 기술 / 배포 (← 우리가 주목할 점)
- **Swift 네이티브** (코드 91.5% Swift), Xcode 프로젝트
- **완전 샌드박스 + entitlement 없음** ← 앱스토어/공증 친화적
- **공증(notarized)** 완료
- **Homebrew 배포**: `brew install --cask tomatobar`
- v3.0+ 에서 Touch Bar·구버전 macOS 지원 제거 (모던 집중)

### 강점 / 약점
- 👍 극도로 가볍고 깔끔, 네이티브, 무료, 자동화 친화(URL 스킴)
- 👎 **뽀모도로 타이머일 뿐** — 휴식 강제·자리비움 감지·건강 케어 없음. 기능 단순

## 2. Stretchly 🧘

> "The break time reminder app"
> https://github.com/hovancik/stretchly — BSD-2-Clause

### 한 줄
**건강·휴식 강제에 특화된 크로스플랫폼 휴식 알림 앱.** 기능이 매우 풍부. **우리 기능 대부분을 이미 무료로 커버** (자리비움 감지·연기·건너뛰기·휴식 사이클).

### 핵심 기능
- **2단계 휴식**: 미니(기본 10분마다 20초) + 롱(30분마다 5분, 미니 2회 후)
- 인터벌·길이 전부 커스터마이즈, **strict 모드**(강제 휴식)
- **연기**(휴식당 1회) / **건너뛰기**(일정 시간 후) / 수동 종료
- **자리비움 감지** — 5분 유휴 시 휴식 일시정지 ("natural breaks")
- **방해금지(DND) 모드 감지**
- 휴식 전 **예고 알림** (미니 10초 전, 롱 30초 전)
- **사운드 테마** 여러 종(crystal-glass, wind-chime, tic-toc, reverie, silence) + 볼륨
- 라이트/다크 테마, 휴식창 색·투명도·블러·크기·위치 커스터마이즈
- **멀티모니터** (전체 화면 / 특정 화면)
- **휴식 아이디어/문구** — 스트레칭·운동 제안을 휴식창에 표시 (HTML 지원)
- **앱 제외 규칙** — 특정 앱 실행 중 자동 일시정지 (발표·영화 등)
- **일출 기반 스케줄링**(위치 기반), 다국어(Weblate 번역), 커스텀 단축키

### 기술 / 배포
- **Electron** (JS 78%) — 크로스플랫폼(mac/win/linux)
- 배포: GitHub Releases, Homebrew, Chocolatey, MS Store, Flathub, Snap
- **미서명** → mac에서 Gatekeeper 우회 필요 (Homebrew `--no-quarantine`)
- 활발한 개발: 1,885 커밋, 58 릴리스, 50+ 기여자

### 강점 / 약점
- 👍 기능 압도적, 무료, 크로스플랫폼, 건강 케어(스트레칭 문구), 커뮤니티 큼
- 👎 **Electron이라 무겁고**, macOS 네이티브 통합 약함, 미서명, UI가 다소 투박

## 3. Fika vs 두 앱 비교

| 항목 | TomatoBar | Stretchly | **Fika** |
|---|---|---|---|
| 형태 | 네이티브 Swift | Electron | **네이티브 SwiftUI** |
| 무게 | 매우 가벼움 | 무거움 | **가벼움** |
| 작업/휴식 사이클 | ✅ | ✅ | ✅ |
| 긴 휴식 주기 | ✅(단순) | ✅ | ✅ |
| 자리비움 감지 | ❌ | ✅ | ✅ |
| **sleep/wake 보정** | ❌ | ❌ | ✅ **(우리 우위)** |
| **휴식 후 복귀 대기(breakHold)** | ❌ | ❌ | ✅ **(우리 우위)** |
| 휴식 강제(화면 덮기) | ❌ | ✅(strict) | ✅(전체화면) |
| 예고 알림 | ✅ | ✅ | ✅ |
| 연기/건너뛰기 | ✅ | ✅ | ✅ |
| **캐릭터/감성** | 토마토 이모지 | 기능 중심 | ✅ **커피 마스코트(우리 강점)** |
| 사운드 테마 다양 | ❌ | ✅ | ❌ |
| 휴식 스트레칭 문구 | ❌ | ✅ | ❌ |
| 앱 제외 규칙 | ❌ | ✅ | ❌ |
| 자동화(URL/Shortcuts) | ✅ | 일부 | ❌ |
| 배포/서명 | 공증+Homebrew | 미서명 | ad-hoc(미배포) |

## 4. Fika가 참고/배울 점

### 당장 가치 있는 것 (Stretchly에서)
1. **휴식 스트레칭/문구** — 휴식 오버레이에 "일어나서 목을 돌려보세요" 같은 짧은 제안 회전 표시. 건강 앱다운 디테일. 구현 쉬움.
2. **사운드 테마 선택** — 지금 단일 사운드 → 몇 종 추가.
3. **앱 제외 규칙** — 특정 앱(영상·발표) 실행 중 자동 일시정지. (NSWorkspace 실행 앱 감지)
4. **방해금지(집중 모드) 감지** — 집중 모드일 땐 알림 자제.

### 배포 전략 (TomatoBar에서)
5. **Homebrew cask 배포** — 앱스토어 대신 `brew install --cask fika`. 개발자들에게 자연스러운 배포.
6. **공증(notarize)** — Developer ID로 공증하면 Gatekeeper 경고 없이 배포 (앱스토어 샌드박스 회피하면서 신뢰성 확보). ← **앱스토어보다 현실적인 길**
7. **URL 스킴 제어** — `fika://breakNow` 같은 자동화 훅. Shortcuts·Raycast 연동.

### 하지 말 것 / 교훈
- TomatoBar처럼 **기능 욕심 줄이고 깔끔함 유지**가 무료 앱의 미덕.
- Stretchly의 기능을 다 따라가면 무거워지고 차별성도 없음 — **커피 마스코트 감성에 집중**.

---

## 5. Fika의 포지셔닝 (결론)

- **기능 신규성으로는 경쟁 불가** — 자리비움·사이클·강제 휴식은 Stretchly가 무료로 다 함.
- **차별점은 둘**:
  1. 🎨 **커피 마스코트 감성** (두 경쟁 앱 모두 없는 것) — "가장 귀여운 휴식 친구"
  2. 🔧 **디테일** — sleep/wake 보정, 휴식 복귀 대기 (둘 다 없는 섬세함)
- **추천 길**: 유료 앱스토어(샌드박스로 유휴감지 위험 + 포화) 대신 → **무료 + Homebrew/공증 배포 + 커피 감성 마케팅**.

> 한 줄 요약: **"Stretchly의 기능 + TomatoBar의 가벼움 + 둘에 없는 귀여움"** 이 Fika의 자리.
