# docs

README에서 참조하는 스크린샷을 이 폴더에 넣는다. 파일명을 아래로 맞추면 자동으로 표시된다.

| 파일 | 내용 | 찍는 법 |
|---|---|---|
| `panel.png`    | 메뉴바 통합 패널 (상태 탭, 진행 링) | 메뉴바 아이콘 클릭 → 패널 열고 `⌘⇧4` 후 `space`로 창 캡처 |
| `break.png`    | 휴식 오버레이 (전체화면 또는 부드러운 효과) | 상태 탭 "지금 휴식하기" → `⌘⇧3` 전체 캡처 |
| `warning.png`  | 휴식 예고 배너 | 작업 시간을 1분으로 두고 예고 배너가 뜰 때 캡처 |

> 권장: 2x Retina 그대로, 가로 800~1200px. 다크 모드 화면이 깔끔하다.
