# Fika ☕️

오래 앉아 있지 않도록, **작업하다가 휴식 시간을 확실히 인지하게** 해주는 macOS 메뉴바 앱.
혼자 쓰는 개인용. Swift + SwiftUI, **Xcode 없이 Command Line Tools 만으로** 빌드한다.

> 이름은 스웨덴어 **fika** — "커피 한 잔과 함께 잠깐 멈춰 재충전하는 시간". 잠깐 쉬자, 라는 이 앱의 정신과 맞닿아 있다.

---

## 핵심 아이디어

알람은 울려도 무시하기 쉽고, "언제 끝났는지"도 잘 모른다. Fika는:

```
작업 중 ──(끝나기 N초 전)──▶ 예고 배너(점점 강조) ──▶ 휴식 알림 ──▶ 작업 복귀
                                  └ 5분 연기            ├ 건너뛰기
                                                        └ 5분 연기
```

- **예고 → 휴식 → 종료** 3단계로, 각 전환을 놓치지 않게 한다.
- 휴식은 **화면을 덮거나(전체화면)** 또는 **부드러운 효과**로 알린다 (선택).
- **자리 비움 감지**로, 이미 쉬고 있으면 작업 타이머를 리셋한다.

## 주요 기능

- **메뉴바 커피 마스코트** ☕ — 작업/곧 휴식/휴식/복귀 상태에 따라 표정·김이 바뀌는 애니메이션 (휴식 화면·진행 링에도 등장)
- **메뉴바 통합 패널** (BetterMouse 스타일 탭 UI): 상태 · 시간 · 알림 · 설정
- **원형 진행 링**: 남은 시간이 단계별 색으로 차오름 (작업=앰버, 곧 휴식=주황, 휴식=청록, 복귀=민트)
- **예고 배너**: 휴식 N초 전부터 상단에 등장, 임박할수록 노랑→빨강
- **휴식 알림 2가지 스타일**
  - `전체화면 덮기` — 작업을 강제로 멈추게 함
  - `부드러운 효과` — 화면 가장자리 글로우 + 작은 카드 (아래는 계속 사용 가능)
- **건너뛰기 / 5분 연기** 버튼
- **"이번만 N분 뒤 휴식"** 빠른 칩 — 영구 설정은 그대로 두고 이번 세션만 조정
- **자리 비움(유휴) 감지** — 키보드·마우스·트랙패드·조이스틱 등 모든 HID 입력 기준. 이미 쉬고 있으면 작업 타이머 리셋
- **노트북 닫았다 열어도(sleep/wake) 정확** — 잔 시간만큼 보정해 깨자마자 휴식으로 떨어지지 않고, 충분히 잤으면 작업을 새로 시작
- **휴식 후 복귀 대기** — 휴식이 끝나도 돌아와 입력할 때까지 작업을 시작하지 않아, 자리 비운 동안 작업 시간이 헛돌지 않음
- **메뉴바 아이콘 테마** — 커피 잔(애니메이션) / 이모지(컬러) / SF 심볼(단색), **컴팩트(아이콘만) 모드**
- **전환 사운드**, **로그인 시 자동 실행**, **멀티 디스플레이 대응**

## 탭 구성

| 탭 | 내용 |
|---|---|
| **상태** | 진행 링 · 세션 수 · 일시정지/재개 · 지금 휴식·건너뛰기·연기 · "이번만 N분" 칩 |
| **시간** | 작업 / 짧은 휴식 / 긴 휴식(시간·주기) / 휴식 예고(초) / 연기 길이 |
| **알림** | 메뉴바 아이콘 테마 · 시간 표시 토글 · 아이콘 미리보기 · 휴식 알림 방식 · 사운드 |
| **설정** | 자리 비움 감지 · 휴식 복귀 대기 · 로그인 자동 실행 · 디버그 로그 · 기본값 초기화 · 종료 |

설정은 **저장 버튼 없이 즉시 적용**된다. 단, 작업/휴식의 "분" 값은 현재 돌고 있는 단계엔 소급되지 않고 **다음 단계부터** 반영된다.

기본값: **50분 작업 · 10분 휴식 · 4번째마다 20분 긴 휴식 · 60초 예고 · 5분 연기 · 자리 비움 5분**.

## 빌드 & 실행

```bash
./build.sh            # swift build (release) → Fika.app 조립
open Fika.app       # 메뉴바에 아이콘 등장
```

콘솔 로그를 보며 실행: `./Fika.app/Contents/MacOS/Fika`
필요: Xcode Command Line Tools (`xcode-select --install`)

친구에게 줄 zip 만들기:
```bash
./package.sh          # → Fika-1.0.zip 생성 + 설치 안내문 출력
```

## ⚠️ 메뉴바에 아이콘이 안 보일 때 (노치 맥)

**앱 문제가 아니라 메뉴바 공간 포화 문제다.** 노치 있는 MacBook은 메뉴바 오른쪽이 꽉 차면,
새 상태 아이콘이 노치 왼쪽(앱 메뉴 영역)으로 밀려 가려진다. 화면이 좁을수록 잘 발생한다.

해결:
1. **알림 탭에서 "메뉴바에 남은 시간 표시"를 꺼서 컴팩트(아이콘만)로** 두면 폭이 최소가 된다.
2. **메뉴바 관리 앱 [Ice](https://icemenubar.app/)**(무료) 설치 후, Fika 아이콘을 **"Always Visible"** 구역에 배치한다. → 노치 화면에서도 항상 보인다.
   ```bash
   brew install --cask jordanbaird-ice
   ```
3. 또는 서드파티 메뉴바 앱 1~2개를 종료해 공간을 확보한다.

> 넓은 외장 모니터에서는 여유가 있어 보통 그냥 보인다.

## 자동 실행 (로그인 시)

기본은 **꺼짐**. 켜려면 **설정 탭 → "로그인 시 자동 실행"**.

안정적으로 쓰려면 **`Fika.app`을 `/Applications`로 옮긴 뒤** 켜는 것을 권장한다
(ad-hoc 서명이라 경로가 바뀌면 로그인 항목이 깨질 수 있음).

```bash
cp -R Fika.app /Applications/
open /Applications/Fika.app
```

## 친구에게 공유 / 설치

App Store 등록 없이 배포 가능. 비공개 레포라면 받는 사람을 **collaborator 로 초대**한다.

> ☕ **받은 친구가 "메뉴바에 안 보여요" 하면** 노치에 가려진 거다 (아래 "노치 맥" 섹션 참고). 앱은 정상 실행 중이니, 메뉴바 정리·Ice 설치로 해결.

### A. 소스로 직접 빌드 (권장, Gatekeeper 경고 없음)
```bash
xcode-select --install
git clone <레포-URL> && cd fika
./build.sh && open Fika.app
```
직접 빌드하면 격리(quarantine)가 안 붙어 경고 없이 실행된다.

### B. 빌드된 .app 내려받기 (GitHub Releases 등)
다운로드본은 격리 딱지를 한 번 풀어야 한다 (ad-hoc 서명):
```bash
xattr -dr com.apple.quarantine /Applications/Fika.app
```
또는 **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**.
경고 자체를 없애려면 Apple Developer ID 서명 + 공증(notarization)이 필요(연 $99, App Store 심사와 무관).

## 프로젝트 구조

| 파일 | 역할 |
|---|---|
| `FikaApp.swift` | 앱 진입점. `NSStatusItem`+`NSPopover`로 메뉴바 아이콘/패널 직접 생성 |
| `Panel.swift` | 통합 패널 (탭바 + 상태/시간/알림/설정 탭, 진행 링, 버튼 스타일) |
| `BreakEngine.swift` | 작업/휴식 상태머신 (두뇌), 진행도·단계 색 |
| `Settings.swift` | 설정 모델, UserDefaults 자동 저장 |
| `Idle.swift` | IOKit `HIDIdleTime`으로 유휴 시간 측정 (모든 HID 장치) |
| `OverlayController.swift` / `OverlayViews.swift` / `OverlayWindows.swift` | 휴식 오버레이·예고 배너·시작 토스트 윈도우와 뷰 |
| `CoffeeAnimation.swift` / `MascotCut.swift` / `CoffeeIcon.swift` | 메뉴바 마스코트(영상 프레임 재생) / 화면 UI 마스코트 컷 / 절차적 컵(폴백) |
| `Log.swift` | 파일 로거(`~/Library/Logs/Fika/`) + 미처리 예외 핸들러 |
| `LoginItem.swift` / `Sound.swift` | 로그인 자동 실행 / 전환 사운드 |
| `Resources/` | `coffee/`(메뉴바 프레임)·`cuts/`(화면 컷)·`AppIcon.icns`(앱 아이콘) |
| `Info.plist` | `LSUIElement`(Dock 미표시)·아이콘 등 번들 설정 |
| `build.sh` / `package.sh` | 빌드+`.app` 조립+ad-hoc 서명 / 친구 공유용 zip 생성 |

## 동작 메모

- 메뉴바 아이콘은 SwiftUI `MenuBarExtra` 대신 **`NSStatusItem`** 으로 직접 만든다 (환경 의존성 회피).
- 유휴 감지는 입력 "내용"이 아니라 **마지막 입력 후 경과 시간만** 읽으므로 별도 권한이 필요 없다.
- Dock 아이콘 없이 메뉴바 전용(`.accessory`)으로 동작한다.
